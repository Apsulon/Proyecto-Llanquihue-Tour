## 📘 Descripción general del sistema

Este proyecto corresponde a la actividad sumativa 1 de la semana 3 de la asignatura Desarrollo Orientado a Objetos I.

Se modela un sistema básico para la agencia de turismo Llanquihue Tour, en la región de Los Lagos. El objetivo es representar de forma estructurada a las personas vinculadas a la empresa, para mejorar la gestión y la organización de sus datos. Todo esto aplicando los principios básicos del DOO, como el encapsulamiento, las relaciones de composición y la herencia.

El sistema permite crear y mostrar información de:

- Direcciones
- Personas
- Empleados
