## 📘 Descripción general del sistema
Este proyecto corresponde a la actividad sumativa 1 de la semana 3 de la asignatura Desarrollo Orientado a Objetos 1.
Se modela un sistema básico para la agencia de turismo Llanquihue Tour, en la regio de Los Lagos.
El objetivo es representar de forma estructurada a las personas vinculadas a la empresa para mejorar la gestión y organización de datos.
Todo esto aplicando los principios basicos del DOO como el Encapsulamiento, relaciones de composicion y herencia.

El sistema permite crear y mostrar información de:
- Direcciones
- Personas
- Empleados
